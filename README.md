# TimerOlahraga
Timer Olahraga adalah aplikasi web timer interval interaktif yang dirancang untuk memandu sesi latihan fisik dan waktu pemulihan. Aplikasi ini memungkinkan pengguna untuk mengatur waktu total, durasi olahraga per set, dan durasi istirahat, serta menyajikan panduan melalui progress bar visual dan peringatan audio dinamis.
